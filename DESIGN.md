# Design system notes

## Reference

- Brand website: [Camelback Nutrition & Wellness](https://www.camelbacknutritionwellness.com/)
- Captured and inspected: 2026-10-23
- Template: community nutrition single-page starter. Existing section order, layout, typography, interactions, and responsive breakpoints are retained.
- Logo: user-provided transparent Camelback Nutrition & Wellness PNG, used in the existing logo placements.

## Color tokens

Extracted from the live site with Firecrawl brand metadata and confirmed against the visual reference. The logo's three principal tones were sampled from the user-provided image.

| Token | Value | Use |
| --- | --- | --- |
| Primary | `#8B3124` | Brand headings, buttons, selected navigation, and primary accents |
| Secondary | `#874034` | Deep brand bands and dark section gradients |
| Accent | `#374659` | Body copy, links, and primary CTA backgrounds |
| Background | `#F2F2F2` | Page background |
| Surface | `#FFFFFF` | Cards and raised surfaces |
| Border | `#D6D6D6` | Dividers and outlines |
| Logo mid-tone | `#CA765D` | Warm coral accent |
| Logo light tone | `#F3C3A9` | Soft peach highlights |

The website extraction also reported `#874034` as a secondary color and `#374659` as both text and link color. Typography and page structure remain those of the supplied template.

## Layout and components

The single page retains the template header and mobile menu, image-backed hero, approach/mission section, biography timeline, credentials, services cards, media training block, media work feature, coverage list, team cards, contact actions, email/media-kit call to action, footer, and theme palette controls. Existing breakpoints and overflow safeguards in `styles.css` are retained.
